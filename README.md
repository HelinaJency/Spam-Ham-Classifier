# Spam-Ham-Classifier
A machine learning project to identify whether a message is spam or ham using text preprocessing and classification algorithms.

## Objective
To classify SMS messages as spam or ham using machine learning.

## Tools Used
- Python
- Google Colab
- Pandas
- Scikit-learn

## Algorithm Used
- Multinomial Naive Bayes

## Dataset
SMS Spam Collection Dataset from Kaggle.

## Accuracy
97.84%

## Features
- Text preprocessing
- CountVectorizer
- Spam prediction
- Model accuracy evaluation
